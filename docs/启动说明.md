# 龙虾脑启动说明

交付版本：v1.5。

本说明适用于当前 macOS 电脑。手机和电脑需要连接同一个受信任的 Wi-Fi；电脑需要保持唤醒。

## 启动

在项目目录执行：

```sh
cd '/Users/mima1234/Desktop/龙虾脑demo'
./start.sh
```

也可以在 Finder 中双击项目内的 `启动龙虾脑.command`。本机需要 Node.js 20 或更新版本；此项目使用 Node.js 原生模块，无需执行 `npm install`。

服务默认使用 8787 端口。启动终端会显示本机访问地址、手机使用的局域网地址和配对码。

1. 先在电脑打开终端显示的本机地址，确认页面能够加载。
2. 手机连接同一 Wi-Fi，打开终端显示的局域网地址。
3. 输入终端显示的配对码。
4. 在手机网页输入任务，查看执行步骤与结果。

配对会话有效期为 24 小时。停止或重启服务后需要使用新配对码重新配对；任务记录保存在 `data/tasks.json`，重启不会清空。执行中和排队中的任务在重启后标记为失败，用户核对电脑状态后可以重试。

局域网地址不能填写为 `localhost`，因为手机的 `localhost` 指向手机自身。

## 演示输入

- `搜索电影`
- `搜索个流浪地球`
- `流浪地球`，也可以替换成其他片名
- `加入腾讯会议，会议码1234`
- `创建一个腾讯会议`

`1234` 只有 4 位，不足以完成腾讯会议入会。普通会议号为 9 位，个人会议号为 10 位。演示此输入时应看到号码不足的提示，不能看到成功入会。来源：[腾讯会议创建快速会议说明](https://meeting.tencent.com/support/topic/389/index.html)。

## 环境要求

电影执行依赖电脑上的浏览器和 Tabbit 工具，默认路径为 `~/.local/bin/tabbit-cli`；安装在其他位置时可用 `TABBIT_CLI` 指定。输入“搜索电影”会在 B 站搜索“热门电影”；输入指定片名时，使用该片名搜索，不再限制为榜单中的英文影片。成功表示对应关键词的搜索结果已经载入，手机会显示搜索关键词、结果链接和截图。如果页面明确显示没有结果，任务仍表示搜索完成，并告知没有找到结果。页面上的结果数仅指当前页面读取到的条目。本版不自动选择或播放视频。

如果 B 站要求验证码、登录或因网络限制无法载入结果，任务会给出具体提示。先在电脑查看 B 站页面并处理提示，再重新提交。搜索结果是否包含某部电影、是否提供正片以及能否播放，由 B 站页面实际内容决定。

腾讯会议已经安装并登录，执行器已获得辅助功能授权。手机尺寸浏览器已完成一次真实自动创建：从提交任务到返回真实会议号和成功状态，执行耗时 6.979 秒。实体手机尚未实测。有效会议号入会仍需在电脑人工确认。实测情况见 [验收记录](./验收记录.md)。

创建成功后会议保持打开。本次执行没有自动确认麦克风和摄像头状态，手机结果会提醒用户到电脑核对。再次创建前应先检查是否已有进行中的会议；已有会议时系统返回处理提示。

### 会议执行器授权与版本限制

会议执行器需要 macOS 14 或更新版本，应用位于项目内的 `.tooling/龙虾脑会议执行器.app`。当前自动创建的页面适配限定为腾讯会议 3.46.0，首页窗口尺寸 720 × 480；页面存在额外弹窗、版本不同或窗口尺寸不符时，系统停止并提示在电脑处理。

1. 打开 macOS“系统设置 → 隐私与安全性 → 辅助功能”。
2. 如果执行器重新编译或签名后仍提示权限不足，先移除列表中的旧“龙虾脑会议执行器”条目，再添加当前应用并开启权限。
3. 添加时选择项目目录中的 `.tooling/龙虾脑会议执行器.app`。选择窗口可按 `Command + Shift + G` 输入完整路径 `/Users/mima1234/Desktop/龙虾脑demo/.tooling/龙虾脑会议执行器.app`。项目移动后应使用新的完整路径；`.tooling` 是隐藏目录。
4. 授权后返回手机页面重试任务，并核对实际结果。系统若提示退出后重新打开执行器，请按提示操作。

屏幕录制权限为可选项。当前实现可通过辅助功能读取会中布局和首页标为“进行中”的同一行会议号，并交叉核对状态；这条路径不依赖屏幕录制，也可能不生成会议截图。若无法取得足够证据，任务保持需要处理。只有采用画面识别或截图时才需要相应屏幕录制权限。

服务通过 macOS LaunchServices 启动已授权的执行器应用，使权限归属于该应用。请通过 `./start.sh` 运行 Demo，不要直接运行应用内的二进制文件代替服务流程。直接作为终端子进程启动时，macOS 可能使用终端或宿主程序的权限身份，导致应用已勾选但仍提示权限不足。

权限由用户在系统设置中调整，Demo 不会自行修改。执行器重新编译、重新签名或移动位置后，应重新检查授权；若系统保留旧条目，移除并重新添加当前应用。

客户端进入会中页面后，首页会议号可能稍后才更新。执行器会继续等待，最长 15 秒。若最终提示未读到会议号，请先在电脑核对会议是否已经创建；不要立即重复提交。

如果本地执行器尚未生成，可运行 `sh scripts/build-meeting-native.sh`；编译需要 Apple Command Line Tools。执行器缺失时服务也会尝试编译，并在失败时返回提示。

## 结束运行

回到启动服务的终端，按 `Control + C` 停止服务。已经打开的浏览器页面或会议窗口可能保留，需要用户自行关闭。

## 无法打开或执行时

| 情况 | 处理方式 |
| --- | --- |
| 手机打不开页面 | 确认电脑服务在运行、双方连接同一 Wi-Fi，并核对局域网 IP；关闭可能隔离设备的访客网络。 |
| 电脑能打开，手机打不开 | 查看 macOS 防火墙或网络隔离设置；确认手机未切到移动网络。 |
| 提示配对失败 | 使用当前启动终端显示的配对码，检查是否多输入空格。 |
| 浏览器工具不可用 | 按本机 Tabbit 的安装说明检查可执行文件和浏览器连接，恢复后重新提交任务。 |
| B 站搜索需要验证码或登录 | 在电脑打开的 B 站页面完成验证或登录，再重新提交搜索任务。 |
| B 站搜索结果未载入 | 核对电脑网络和 B 站页面上的提示；没有结果证据时任务不会显示成功。 |
| 提示腾讯会议未安装 | 当前本机已安装。若在其他电脑运行，请安装并登录官方客户端；非默认路径可设置 `TENCENT_MEETING_APP`。 |
| 提示缺少辅助功能权限 | 检查当前执行器的辅助功能授权；重新编译或签名后，移除旧条目并重新添加当前 `.app`。 |
| 提示已存在会议 | 在电脑确认当前会议，离开或结束后再提交创建任务。系统不会为这条指令重复建会。 |
| 会议已打开，但未读到会议号 | 先在电脑核对是否已经建会，处理当前会议后再决定是否重试。此任务不会记为成功。 |
| 有效会议号仍需人工确认 | 本版自动入会尚未验收，请到电脑填写会议号并确认音视频选项。 |
| 会议号无效 | 向会议组织者核对完整会议号；不要随机补齐数字。 |
| 提示会议版本或窗口不受支持 | 当前适配腾讯会议 3.46.0 的 720 × 480 首页；关闭额外弹窗，或在电脑手动操作。 |
| 需要登录、验证码或系统授权 | 到电脑完成对应操作后重试，手机端不会代填账号密码。 |
| 页面显示连接断开 | 唤醒电脑并确认服务仍在运行，然后刷新手机页面。 |

此版本使用本地 HTTP，仅用于受信任网络中的演示。不要通过路由器端口映射直接开放到公网。

## 执行限制

电脑一次执行一个任务。排队中和执行中的任务合计最多 5 个；单次执行超过 150 秒后返回超时失败。取消只能阻止后续步骤，无法撤回已经发给腾讯会议的操作；通过 LaunchServices 启动的执行器可能仍在执行该操作。已经打开的页面或会议可能保留，需要在电脑核对。

重试会创建一个新任务并保留原任务，沿用原始指令。如果需要修改无效会议号，应编辑输入后重新提交。

如果 8787 端口被占用，可以执行：

```sh
PORT=8788 ./start.sh
```

此时使用终端显示的 8788 地址。
