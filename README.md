# 龙虾脑 Demo

交付版本：v1.5。

手机网页输入一句话，由这台 Mac 执行，并把进度、结果和异常返回手机。

```sh
./start.sh
```

也可以双击 `启动龙虾脑.command`。服务启动后，在电脑打开 `http://localhost:8787`；手机使用启动终端显示的局域网地址，并输入六位配对码。手机和电脑需要连接同一个 Wi-Fi。

当前电影流程改为在电脑打开 B 站搜索。输入“搜索电影”会搜索“热门电影”；输入“搜索个流浪地球”或直接输入片名，会搜索对应关键词。搜索结果载入后，手机收到关键词、链接和截图；本版不自动播放视频。验证码或网络限制会返回具体提示。无需 API Key，运行时使用限定场景的规则识别。

腾讯会议已安装并登录，执行器已获得辅助功能授权。手机尺寸浏览器已完成“创建一个腾讯会议”的实际执行，6.979 秒后收到真实会议号和成功状态；结果由会中界面与首页进行中的会议记录交叉确认。本次未自动确认麦克风和摄像头状态，页面会提示到电脑核对。有效会议号加入仍需要在电脑上确认，1234 会返回格式错误。实体手机尚未实测，授权和版本限制见启动说明。

交付文件：

- `docs/龙虾脑产品方案.pdf`：产品定位、流程、边界、指标和后续版本规划。
- `docs/启动说明.md`：环境、手机接入、启动与停止、异常处理。
- `docs/验收记录.md`：实际测试结果和验证范围。
- `public/product.html`：可在浏览器阅读和打印的产品方案。
- `artifacts/龙虾脑演示.mp4`：历史播放版本的真实浏览器录屏，电影段使用 Rotten Tomatoes 预告片，会议段记录了当时未安装客户端的提示；它不代表当前 B 站搜索流程。
- `artifacts/腾讯会议权限反馈.mp4`：此前未授权版本的录屏，展示权限提示和运营看板的实际反馈。
- `artifacts/腾讯会议自动创建.mp4`：当前自动创建流程的录屏，展示手机尺寸网页提交、电脑创建、真实会议号回传和运营看板。

运行环境为 macOS、Node.js 20+、Tabbit 及其 `~/.local/bin/tabbit-cli`。会议执行器需要 macOS 14+，源码位于 `scripts/meeting-native.swift`，通过 `sh scripts/build-meeting-native.sh` 编译。交付包附本机编译的 Apple Silicon 版本。本项目没有运行时 npm 依赖。测试命令为 `npm test`。

任务记录位于 `data/tasks.json`，截图和执行证据位于 `artifacts/`。当前记录为本次开发验收实际产生的测试任务。文件保存在本机，服务使用局域网 HTTP，适用于受信任网络中的演示。
